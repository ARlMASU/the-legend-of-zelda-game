# The Legend of Zelda - Koçak Onur (projet Tangara)

## Features du jeu

- 128 écrans différents sur lesquels se déplacer
- Des ennemis sur chaque écran, avec une IA de déplacement et de tir
- Différents systèmes :
    - Vie (gagner des réceptacles de cœurs, perdre et gagner de la vie)
    - Attaque (épée)
    - Défense (renvoyer les projectiles avec le bouclier)
    - Monnaie
    - Récupération/achat d'objets (cœur, épée)
    - Animation et déplacement poussés
    - Projectiles
    - Sons
    - Musique
    - ...

## Étapes d'une partie

1. Récupérer l'épée dans la grotte du première écran
2. Se balader et tuer des ennemis
3. Gagner des rubis
4. Acheter des réceptacles de cœur pour pouvoir explorer plus loin

## Mécaniques à connaître

- Link peut renvoyer les projectiles avec son bouclier, il lui suffit de se positionner dans la direction opposée à celle du projectile.
- Il y a deux types de rubis :
    - jaune qui augmente le compteur de 1,
    - bleu qui augmente le compteur de 5.
- Les ennemis peuvent tirer à travers les murs, mais doivent être aligner avec Link sur l'axe X ou Y.

## Commandes

| Touche | Fonction                                                |
| ------ | ------------------------------------------------------- |
| Z      | Aller en haut                                           |
| Q      | Aller à gauche                                          |
| S      | Aller en bas                                            |
| D      | Aller à droite                                          |
| E      | Attaquer (si l'on possède l'épée)                       |
| F      | Objet secondaire (non-utilisé dans la version actuelle) |
